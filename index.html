          How this works
          

            This page reads your file in memory a few megabytes at a time. Each message's date is
            checked against the fixed period (March 1 – August 31, 2026, your computer's local time)
            before anything else is done with it — messages outside that period are skipped and never
            decoded or written out. Messages inside the period are converted and written either straight
            to a file you choose (Chrome or Edge on a computer) or to a normal download (other browsers).
            No part of the file is ever sent anywhere — there is no server behind this page, only the
            code running in this tab. Attachments are listed by name and size rather than included, to
            keep the output readable. View this page's source at any time to check for yourself.
