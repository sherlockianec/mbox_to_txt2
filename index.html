Mbox Email Extractor

Pick a date range, get back a clean plain-text file of just those emails — subject, date, sender, recipient, attachment names, and body text. Nothing else.

Everything happens on this device. The file is read locally by your browser and never leaves it — this page makes no network requests at all (try it with Wi-Fi off). Close the tab when you're done and nothing is kept.
